Six supplied logo files, used as supplied and never redrawn. The mark's orange is `logo-orange` (#EC6A23); it is not `signal` and is never changed.

- `k7-cybersecurity-logo.svg`: full horizontal logo, orange mark with dark wordmark. Light theme header and footer, print.
- `k7-cybersecurity-logo-white.svg`: full horizontal logo, orange mark with white wordmark. Dark theme header, the footer (contrast ground), any dark imagery.
- `k7-cybersecurity-logo-square.svg` and `k7-cybersecurity-logo-square-white.svg`: stacked variants for square placements (social avatars, app tiles), dark and white wordmark respectively.
- `k7-icon.svg` and `k7-icon-white.svg`: the mark alone, for favicons, 32px placements and the Media Centre "Icon" download; the white variant carries a white keyline for dark grounds.

Minimum height in the header is 26px (full logo); clear space on every side equals the height of the mark. Media Centre offers the primary, compact and icon variants for download from these files.
