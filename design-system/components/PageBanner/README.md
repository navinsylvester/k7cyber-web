# PageBanner
The opening sheet of every inner page: a meta line, the page title in `h-page` flush left, and beside it the lede with the page's actions.

**Use** where the content doc says "Banner Image": product, addon, industry, service, compliance, listing and company pages. The meta line carries the section path on the left (`Platform · Core`) and one fact on the right. Listing and data pages use the compact form (`h-util` with the section icon, A1) so the list sits near the fold.

**Provide** the title (the page's H1, exactly as the content doc writes it), the lede, up to two actions (primary first), and the meta strings. A banner image, where one exists, goes in a `ph` frame below the grid with a caption; the sheet never becomes a full-bleed image.

**Don't** centre the title, add a background image behind type, or stack three actions. Breadcrumbs, where needed, replace the meta line's left side.
