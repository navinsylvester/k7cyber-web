# StatRow
A ledger of facts: the number in `num` (Archivo width 62) on the left, its description in `muted` on the right, one hairline per row.

**Use** for "Globally Recognised Cyberthreat Research" on the home page, the About page, and any trio of proof points. Rows, not tiles.

**Provide** {number, description}. Numbers are real and sourced; the content doc gives 30+ years, millions of devices, 27 countries.

**Don't** animate counters, add icons, or invent figures. Keep to three to five rows.
