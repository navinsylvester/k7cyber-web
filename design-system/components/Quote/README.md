# Quote
A customer testimonial: the person (avatar or logo, name, company, optional tag) on the left, the quote in Archivo at 28px on the right, opened with a `acc-ink` quotation mark.

**Use** for the testimonial carousel on the home page, the single quote on each industry page, and the list on the Testimonials page. The carousel is a row of 32px bars; the current one is `ink`.

**Provide** the quote (verbatim, trimmed to the strongest four lines), name, designation or company, and a customer logo where supplied (replaces the avatar initials). Tag the regulation or service it evidences.

**Don't** italicise, add stars, or fade quotes in. One quote visible at a time.

**shadcn** Carousel for the home page; a plain list elsewhere. Payload: `testimonials` block relating to the `testimonials` collection.
