# ReportCover
L6, one HTML cover for every Cyber Threat Monitor issue: a filed sheet (S7) on ink. The Labs icon and name sit on the cover's tab, scaled with the cover (15cqw tall); under it the square body (`cover-body`) carries the series, the period in Archivo width 62 closing with the signal pixel, and the date range in the foot. Until 2.2 the corner was cut 9%; now only the tab is cut, on the 7.

**Use** on Threat Reports and wherever the home page or an industry page links to the K7 Cyber Threat Monitor report. Only the period and its dates change.

**Provide** {period ("Q2 2026", "Annual 2025"), date range}. Width sets everything else through container units.

**Don't** replace it with a PDF thumbnail; the cover is the thumbnail.
