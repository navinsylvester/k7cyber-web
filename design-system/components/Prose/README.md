# Prose
Long-form copy at 18px/1.65 in a 40rem column: headings, square bullets, callouts, code where a page needs it.

**Use** for About K7, compliance pages (ADHICS, CBUAE, DPDP), blog posts, press releases and legal pages. Rich text from Payload's Lexical editor renders here.

**Provide** the rich-text tree. A `callout` holds one labelled sentence; a `notice` is a framed advisory.

**Don't** widen the column, use drop caps, or inline images without a `ph` frame and caption.
