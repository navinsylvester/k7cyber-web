# LeaderRow
The Leadership page as an index: a 64px photo (or initials), the name, the role, and an arrow to the profile.

**Use** on Leadership only. Rows invert on hover like every index row.

**Provide** {photo, name, role, profile href}. Photos are square, greyscale, 64px. Where the content doc has "Person 1", keep the role and leave the name to follow rather than inventing one.

**Don't** use a card grid of portraits, or add social icons per person.
