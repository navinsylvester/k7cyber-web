# Switchboard
"Modular by design" in two columns, not a grid of tiles. The **core** is one filed block on paper (S7), its tab reading `Core · 04 · Always on`: the four names set large on hairlines, each with a mono gloss of a few words under it (`EPP`, *Endpoint protection platform*), and the base line `1 agent · 1 console`, because everything in the block runs on them. The **add-ons** are a ledger of seven rows beside it, each its index in `acc-ink`, its name and gloss, and an **Off | On** switch on the segmented control the header's theme toggle uses; a row that is on has its index stamped as a block of ink, no transition. The block's tab sits level with the ledger's head. Under both, the sum on a double rule, the rule a sum earns (Account): `05 of 11 modules on` in the counting width, the add-ons picked, and one text link whose URL carries the modules that are on. Throwing a switch stamps the index, steps the count and changes the link. No icons and no descriptions: the detail is the Platform page's, reached by the action under the sum. Nothing inverts on hover but the switch.

Since 2026-10-21; before it the board was eleven cells with a description each on one rail, which read as the Platform page compressed.

**Use** on the home page in place of ModuleChips, where a visitor should see at a glance what is always on, what can be switched on, and that it all runs on one agent and one console. The add-ons are the moat, so they take the wider column. The Platform page keeps the tiles and the descriptions.

**Provide** two groups, core then add-ons, of {name, line, on, href}, the line a gloss of three to six words; the groups' labels and notes (`Core`, `04 · Always on`; `Add-ons`, `07 · Switch on as required`); the tally's note (`1 agent · 1 console`, split at the dot onto the block's base) and request URL; and one action to the Platform page. Keep the content doc's order.

**Don't** make a core row a switch, add icons or the full descriptions, invert a row on hover, colour rows by category, switch add-ons on by default, ease the stamp, or use the double rule for anything but the sum.

**Build** the `ModuleGrid` block with `layout` set to switchboard (`Switchboard.client.tsx`; `switchboard`, `sw-core`, `sw-names`, `sw-name`, `sw-gloss`, `sw-base`, `sw-head`, `sw-ledger`, `sw-row` and the shared `module-tally` in `bundle.css`). From 1000px the block takes five twelfths and the ledger seven, stretched to one height so the four core rows share the ledger's height; below that the block sits over the ledger.
