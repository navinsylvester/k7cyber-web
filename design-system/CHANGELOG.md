# Changes to the K7 Design Language in this repository

Newest first. Each entry names the rule, the reference CSS and the parts it touched, so the system describes the site as built (README.md, "Keeping it current"). Until 2026-10-15 the folder mirrored the Design System artifact unchanged (SOURCE.md).

## 2026-10-16

- **Switchboard**, a new part: "Modular by design" on the home page as a board on one rail in place of the tiles. Core cells above the rail, each marked On as a block; add-on cells below, each with an Off | On switch on the segmented control; every cell plugged into the rail by a tick, with an ink plug on the rail when the module is on; the rail labelled `1 agent` and `1 console`; the sum line beneath (`04 of 11 modules on`, the add-ons picked, the request link that carries them). Only the switch inverts. `Switchboard.client.tsx`, the `moduleGrid` block (`layout`); `.switchboard`, `.sw-*` in `bundle.css`; Switchboard README and preview; ModuleChips README; the Home artboard and seed.
- **Receiver**, a new part: the home page's testimonials as stations on a band. A status line with the live pixel (`RECEIVING · CH 01/03 · company · tag`), the transmission at full width (the quote, name and company, no portrait), and a scale of ticks with the stations printed on it at their positions, the current one inverted, whose needle sweeps in steps to the next station; the arriving quote is replaced with no transition and its station's pixel stamps. Two bands on one switch (`rx-band`, the segmented control): praise, and complaints, which nobody shows and we do, each negative testimonial named Interference with K7's one-line reply as a block under it (`sentiment`, `reply`), genuine and fair first, funny second. Hover holds, a press tunes, reduced motion rests. `Receiver.client.tsx`, the `testimonials` block (`receiver`, `dwell`); `.rx-*` in `bundle.css`; Receiver README and preview; Quote README; the Home artboard and seed (two in-house drafts stand in for the quotes still owed).
- **ReportCover, the award**: the record sheet's AMTSO panel carries a drawn cover like the report beside it (AMTSO on the tab with the certificate glyph, the award's title as the series, RTTL as the figure, the foot), in place of the placeholder; the cover's glyph is a field (`icon`, archive for a report, certificate for an award). `FeaturePanels` block, `Cover.tsx`; the Home artboard and seed.
- **Account**, a new part: a ledger that sums. Entries set large on hairlines with their index in `acc-ink`, the last row the total under a double rule with its value stamped as a block (`term`), and the statement beside at lede size with its terms as blocks. The home page's "Security that answers to you" (Why K7) is built on it in place of the fact ledger beside body copy, its statement filed beside a drawn cover (Accountability · Since 1991) on the record sheet's FeaturePanel and ReportCover, on paper (`feature.on-paper`); `Cover.tsx` is now shared by the two blocks. `.account-layout`, `.account`, `.account-sum`, `.account-copy` in `bundle.css`; the `intro` block (`account`); Account README and preview; the Home artboard and seed.
- **CapabilityRow, numbered**: the home page's four capabilities set as a ledger of four rows, each with its index large in the counting width and the icon under it, the title and sentence beside, and its tags as a scope headed by what it is and how many (`Covers · 06`), the tags a size up (13px) in ink and filled with signal while the row is hovered (the inversion, 240ms). Three columns from 1000px, stacked on a phone. `.cap-ledger`, `.cap-n`, `.cap-body`, `.scope` in `bundle.css`; the `capabilityRows` block (`numbered`, row `scopeLabel`); CapabilityRow README and preview; the Home artboard and seed.
- **IndexRow, the glyphs**: an index whose rows are kinds of thing may carry one 32px icon per row, set before the arrow in a column of its own (`ilist-glyphs`) so the arrows stay in line; the industry index on the home page carries the seven industries. **Icon** gains those seven on the icon rules: bank, mortarboard, capitol, cross, factory, terminal, bag, each with its one pixel placed where it means something. `Icon.tsx`; the `indexRows` block (row `icon`); `.ilist-glyphs` in `bundle.css`; IndexRow and Icon READMEs and previews; the Home artboard and seed.
- **The puzzle sheet, rebalanced**: the lede ("Cybersecurity is getting lost…") sets above "Beyond the obvious." as a kicker in the left column, and the answer on the right sets at lede size beside the puzzle glyph so the column fills; its five sources (endpoints, identities, data, vulnerabilities, behaviour) are **terms**, inverted blocks of ink on ground in either theme. `SheetHead` (`kicker`), `withBold(text, 'term')`, the `intro` block's symbol layout; `.kicker`, `.term` in `bundle.css`; SheetHead README; the Home artboard and seed.
- **The puzzle sheet, unstepped**: "Beyond the obvious." no longer sets as the stair; it sets on one or two lines with the redacted word, so the home page carries no stair headline (S4 stays for chain figures and stacked content). The spec strip under the sheet (Agentic SOC · Platform · Sensor) is gone; the hero's stack already says it. `intro` seed (no `stair`, no `specs`); README S4; SheetHead README; the Home artboard.
- **The tab on the hatched sheet**: the contrast sheet with the seven hatch (PT2) no longer clips itself, and the rule that lifts its content over the pattern leaves the sheet tab out, so "05/09 Industries" rises above the sheet's top edge like every other tab instead of sitting in the content. `globals.css` (`.sheet.has-pattern`); the Home artboard (no `overflow: hidden` on the industries sheet).
- **Icon, the puzzle**: a ninth content glyph on the icon rules, three 11px pieces in an L and the fourth slot empty but for the pixel that marks the missing piece. It sits at 80px beside the "Beyond the obvious" paragraph in a `symbol-row` (icon and copy sharing a row, as a capability row does; 64px and stacked below 520px), the three pillars on a spec strip below. No figure, no motion. **SheetHead gains an aside**: content stacked under the lede in the right column (`head-aside`), so a stair headline has a filled column beside it instead of a lede alone at its foot. `Icon.tsx` (`puzzle`), Icon README and preview; `.head-aside`, `.symbol-row` in `bundle.css`; `Sheet.tsx` (`aside`); the `intro` block's `symbol` select; SheetHead README; the Home artboard.
- **Hero, the stack**: the hero headline is the product name, one word per line, flush left (`h-hero`), neither stepped nor redacted; beside it the stack figure (`hero-fig`, `stack`): sensor, platform and agentic SOC as three tab-shaped plates on the 7, the top one narrower so it sits on the one below, two square-capped arrows up the chain, mono labels and the pillar lines, and one signal pixel climbing in five steps (`k7-climb`, `steps(1)`), resting on the top plate under prefers-reduced-motion. **S3 and S4 move off the hero**: the stair and the redacted word open the sheet after it, "Beyond the ████.", through SheetHead's `stair` and `redact` (the `intro` block). README Signatures S3, S4 and Patterns and figures; Hero README and preview; `bundle.css` (`.h-hero`, `.hero-body`, `.hero-copy`, `.hero-fig`, `.stack`, `.stair` now only the steps, `.sheet-head > .h-wrap`); `HomeHero` block (`figure`, no `redactNote`), `Intro` block (`stair`, `redact`, `redactNote`), `Sheet.tsx`; the Home artboard.
- **Home page content**: the page now carries the content doc's Home Page section as the 2026-10-15 mockup orders it, on the case-file parts and nothing from the mockup's own design: the stair sets the product name (K7 / Seventh / Sense, the last word redacted) over the hero line "Unified Endpoint-To-SOC Security Platform"; "Beyond the obvious" opens the next sheet with its two paragraphs and the three pillars; the four capabilities are a sheet of their own; the modular grid is two groups, Core (EPP, EDR, XDR, MDR, on) and Add-ons (seven, off); the industry index names IT/ITES; "Security that answers to you" files the three commitments as a ledger; the record keeps the award, the report cover and the three figures; the quote is verbatim, with the two placeholders the doc still owes. Nine sheets; the closing signal sheet is the design system's own. `src/endpoints/seed/pages.ts` (`homePage`), `scripts/seed-page.ts` (`pnpm seed:page home` reseeds one page), the Home artboards; Hero README (the lede is the hero line).
- **ModuleChips, the tally**: a bar under the grid counts the modules that are on (`08 modules active`, a figure at width 62 that steps as add-ons are pressed) with the note `1 agent · 1 console`, the add-ons picked and one text link whose URL carries the modules (`?modules=EPP,EDR,…`); the groups share one state. Each tile now draws its own hairline (`.module`, `.module-legend` box-shadow; the grid has no line background), so a short last row leaves the ground bare rather than a block of line. `bundle.css` (`.module-tally`, `.module-legend`), `ModuleGrid` block (`tally`, `tallyNote`, `requestUrl`; `Tiles.client.tsx` is `ModuleGroups`), ModuleChips README and preview, the Home artboard.

## 2026-10-15 · 2.2, the case file

- **The language is named**: K7 Design Language is a case file. README opens with the two marks, the pixel and the tab; new sections *The pixel*, *The test* (would it survive a photocopy?) and *The words*; the Signatures keep S1 to S6 and gain S7 Filed and S8 The record rail. `tokens.json` is version 2.2.
- **S2 The Seven** replaces the cut. The 7 in `k7-icon.svg` is 24.5° from vertical, descending left; the old cut was a 45° top-right chamfer, its mirror. New tokens `seven` and `seven-run`; `cut-tab`, `cut-btn` and `cut-feature` are gone. Every tab's right edge now runs its full height on the 7 (`--tab7`): `.sheet-tab`, `.rtab` (and the 40px workspace tabs in `portal.css`), `.btn-primary`, `.btn-ink`, `.btn-sm`, the new `.wordmark-mark`. Nothing else is cut. `bundle.css`, `tokens.css`, `globals.css` comment; SheetTab, Button, Tab previews.
- **S7 Filed** (`.filed`, `.ftab`, `.ledger`, `.ledger-hint`, `.code` in `bundle.css`; new part `Tab`): the feature panel's label moves onto its tab and the panel's corner is square (`FeaturePanels` block, the blog's `PostFeature`, the threat-reports lead; FeaturePanel README and preview; the Home and Platform artboards); the Labs vulnerability and top-threats ledgers and the support products and customers lists raise the results line as their tab with the heads on a band (DataTable README and preview, LabsParts L4, SupportParts S7); the report cover's series label is its tab over a square `cover-body` (`Cover.tsx`, the home cover, ReportCover README and preview, the Home artboard); code is filed with the language and the line count on its tab (`Code` block, `research.css`); the lead dialog is a filed sheet whose tab carries the report title (`Lead.client.tsx`, `research.css`, LabsParts L11).
- **S4 The stair** steps .82em, .41em, 0 so the line starts sit on the 7 (`bundle.css`; Hero README). **PT2 Seven hatch** is drawn at 24.5° (`M14.56 0 L5.44 20`: `IndexRows` block, Pattern README and preview, the Home artboard, the Cover poster).
- **Motion**: said things ease, counted things step; a thing that arrives is stamped, `.pixel.is-stamp` blinks twice (the lead dialog). Written in Type and Layout and motion; no eased counter existed to remove, and StatRow stays still.
- **S8 The record rail** on Labs pages only: `Prose` numbers paragraphs when given `rail` (the post page) and the CVE record numbers its technical information (`.record`, `.para`, `.para-n` in `research.css`; LabsParts L13; Prose README).
- **The pixel** is named as the crown jewel: README section, `tokens.json` usage, Icon README; `.pixel` comment in `bundle.css`.

## 2026-10-15

- **Icon, SiteFooter**: five social glyphs (LinkedIn, X, YouTube, Instagram, Facebook) drawn on the icon rules, each with its one pixel placed where it means something. SiteFooter shows them at 32px in the 36px frames in place of the two-letter mono codes, which remain the fallback for a network without a glyph. `src/components/k7/Icon.tsx` (`social`), `src/Footer`, the desktop artboards and `designs/k7chrome.py`, the Icon and SiteFooter previews.
- **FeatureMatrix**: included is the glyph ✔ in ink, not a signal pixel per cell; the one pixel stays in the `is-k7` head. Content fundamentals now say the pixel is for a single state and the glyph for a ledger. `bundle.css` (`td.tick`), the block, the MDR artboard, the FeatureMatrix preview.
- **Photography and illustration**: inside a figure frame (`.ph`) and in portraits (`.avatar`) every photograph and illustration renders greyscale; a drawn cover (`.is-cover`) keeps its colour; figures inside an article keep theirs. Written for the Lab Blog's imported featured images. README (Patterns and figures), Placeholder, `bundle.css`.
- **Building in React**: the stock shadcn parts were removed from `src/components/ui` with the packages only they used; the README's consuming section is rewritten, each part's `**shadcn**` line is now a `**Build**` line naming the real block or component, and "Where each part lives" and "Keeping it current" are added. The theme attribute is rendered on the server so nothing is hidden before paint.
- **LabsParts**: the README now covers the whole of section 08 (utility header, research bar, ledger, Lab Blog, post, detail pages, threat reports, the Labs landing), not only the three identifier parts.
